# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticise code and designs rather than people, and remember that blunt security review is welcome while personal attacks are not.

Report unacceptable behaviour to the maintainers through the repository's private contact (see [`SECURITY.md`](SECURITY.md) for the channel). Reports are handled confidentially.
